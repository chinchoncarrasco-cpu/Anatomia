Sistema inmunitario

Parte del sistema inmunitario humano.

¿Qué es?

El sistema inmunitario protege al organismo frente a microorganismos, células dañadas y sustancias extrañas.

Dos grandes defensas

  • Inmunidad innata: actúa rápido y reconoce peligros generales.
  • Inmunidad adaptativa: reconoce objetivos específicos y puede formar memoria.

Componentes principales

Leucocitos Linfocitos Neutrófilos Macrófagos Células dendríticas Anticuerpos Médula ósea

Respuesta básica

Peligro → reconocimiento → activación → eliminación → memoria posible

Dato importante

El sistema inmunitario necesita distinguir entre lo propio y lo extraño para proteger sin dañar innecesariamente al cuerpo.

Truco para recordar

Detecta, comunica, ataca y recuerda.
