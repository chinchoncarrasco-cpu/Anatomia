Sistema nervioso

Introducción al sistema nervioso.

¿Qué es?

El sistema nervioso recibe información, la interpreta y coordina las respuestas del cuerpo.

Divisiones principales

  • Sistema nervioso central: encéfalo y médula espinal.
  • Sistema nervioso periférico: nervios que conectan el sistema central con el resto del cuerpo.
  • Sistema nervioso autónomo: regula funciones involuntarias, como el ritmo cardíaco y la digestión.

Funciones

Participa en la sensibilidad, el movimiento, el pensamiento, la memoria, el lenguaje, las emociones y el control automático de los órganos.

Recorrido básico

Estímulo → receptor → nervio sensitivo → cerebro o médula → nervio motor → respuesta

Dato importante

El cerebro no trabaja solo: depende de la médula espinal y de los nervios para comunicarse con el cuerpo.

Truco para recordar

Central procesa; periférico conecta.
