# Anatomía fácil — Versión 2 unificada

Esta versión reúne todos los sistemas creados hasta ahora y corrige el menú lateral.

## Sistemas incluidos
- Circulatorio
- Respiratorio
- Urinario
- Hepático y biliar
- Digestivo
- Endocrino
- Nervioso
- Óseo
- Muscular
- Linfático
- Reproductor masculino

## Cómo instalar
1. Descomprime el ZIP.
2. Borra o reemplaza los archivos actuales del repositorio.
3. Sube todos los archivos de esta carpeta a la raíz.
4. Confirma los reemplazos.
5. Espera unos minutos y recarga GitHub Pages.

El menú está incluido directamente en todas las páginas y ya no depende de parches sucesivos en app.js.
